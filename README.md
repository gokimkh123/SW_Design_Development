## 추진 배경

- 기숙사 2인실 룸메이트 배정은 대부분 무작위 또는 단순 설문 방식
- 설문 점수만으로는 **"새벽 1시 통화"** 등 실제 생활 장면에서의 반응 예측 불가
- 갈등은 입주 후에야 드러나며, 관계 악화 및 재배정 민원으로 이어짐

```mermaid
flowchart TB
    subgraph NOW["기존 · 무작위 배정"]
        direction LR
        n1["입사 첫 주<br/>무작위 배정<br/>규칙 합의 없음"] --> n2["3주 차<br/>새벽 게임 소음<br/>수면 부족 누적"] --> n3["6주 차<br/>직접 언급 부담<br/>관계 악화"] --> n4["8주 차<br/>재배정 민원"]
    end
    subgraph NEW["룸메궁합"]
        direction LR
        m1["입사 전<br/>가상 동거 기반<br/>수면 리듬 충돌 사전 확인"] --> m2["매칭<br/>수면 리듬 일치<br/>후보 선택"] --> m3["입주 첫날<br/>생활 규칙 6개 합의"] --> m4["학기 중<br/>AI 중재 기반<br/>불편 조기 해소"]
    end
    NOW ~~~ NEW

    classDef bad fill:#fee2e2,stroke:#dc2626,color:#7f1d1d
    classDef good fill:#d1fae5,stroke:#059669,color:#064e3b
    class n1,n2,n3,n4 bad
    class m1,m2,m3,m4 good
```

**룸메이트 갈등 주요 원인** (영국 대학생·학부모 4,000명 이상, 복수 응답, 2026)

## 서비스 개요

| | 기능 | 내용 |
| --- | --- | --- |
| 1 | **생활 페르소나** | 생활 설문 8문항 + 상황 질문 4문항 기반 수면 · 청결 · 소음 · 대화 방식 분석 및 AI 분신 생성 |
| 2 | **가상 동거 시뮬레이션** | 사용자 AI와 후보 AI 간 가상 7일 · 생활 장면 20개 동거 및 장면별 대화 · 조율 |
| 3 | **생활 규칙 자동 작성** | 시뮬레이션 합의 내용 기반 6개 영역 생활 규칙 초안 작성 |
| 4 | **AI 중재** | 입주 후 불편 사항의 요청형 문장 변환 및 규칙 재협상 지원 |

### 사용자 흐름

```mermaid
flowchart LR
    A["A 생활 페르소나<br/>설문 · 상황 질문<br/>→ AI 분신 생성"] --> B["B 가상 동거<br/>후보 3명 대상<br/>7일 · 장면 20개"]
    B --> C["C 매칭 · 생활 규칙<br/>리포트 기반 선택<br/>→ 규칙 초안 합의"]
    C --> D["D 입주 후 관리<br/>불편 전달 · 체크인<br/>AI 중재"]
```

### 가상 동거 시뮬레이션 구조

```mermaid
flowchart LR
    PA["하늘 AI<br/>규칙적인 아침형"] --> MOD
    PB["다은 AI<br/>깔끔한 집순이"] --> MOD
    MOD["시뮬레이션 진행자<br/>가상 7일 · 장면 20개<br/>순차 제시"] --> TALK["장면별 대화<br/>AI 간 직접 조율"]
    TALK --> J{"판정"}
    J -->|"원만"| NEXT["다음 장면"]
    J -->|"조율"| RULE["규칙 후보 저장"]
    J -->|"충돌"| MED["합의안 제안"]
    RULE --> NEXT
    MED --> NEXT
    NEXT -.->|"20개 장면 반복"| MOD
    NEXT --> OUT["궁합 점수 · 리포트<br/>생활 규칙 초안"]

    classDef ai fill:#ccfbf1,stroke:#0d9488,color:#134e4a
    classDef out fill:#e0e7ff,stroke:#4f46e5,color:#312e81
    class PA,PB ai
    class OUT out
```

**생활 장면 20개**

| 카테고리 | 장면 |
| --- | --- |
| 수면·소음 | 새벽 통화 · 심야 게임 · 이른 알람 · 드라이기 소음 |
| 청결·청소 | 설거지 미루기 · 욕실 머리카락 · 청소 당번 |
| 공용 물품 | 냉장고 반찬 · 휴지·세제 소진 · 물건 무단 사용 · 공과금 분담 |
| 방문객 | 친구 초대 · 연인 방문 · 늦은 귀가 |
| 환경 | 난방 온도 · 환기 · 조명 |
| 특수 기간 | 시험 기간 · 실습 주간 · 주말 늦잠 |

## 팀 구성 및 역할

```mermaid
flowchart LR
    PM["건한<br/>역할 1 · PM · 기획 · QA"]
    AI["건한<br/>역할 4 · AI 시뮬레이션 엔진"]
    FE["동현<br/>역할 2 · 프론트엔드"]
    BE["일준 · 범찬<br/>역할 3 · 백엔드 · 데이터"]

    PM -->|"설문 문항 · 장면 템플릿 20개"| AI
    PM -->|"화면 설계 · 우선순위"| FE
    AI -->|"엔진 함수 인터페이스"| BE
    BE -->|"REST · SSE API"| FE
    FE -->|"통합 빌드 · 버그 리포트"| PM
```

| 역할 | 담당 | 담당 업무 | 폴더 |
| --- | --- | --- | --- |
| **1. PM · 기획 · QA** | 건한 | 일정 관리, 설문 문항 · 생활 장면 20개 작성, 통합 테스트, 포스터 · 발표회 운영 | `docs/` `data/` |
| **2. 프론트엔드** | 동현 | 모바일 웹 화면(흐름 A~C), 시뮬레이션 실시간 화면 | `frontend/` |
| **3. 백엔드 · 데이터** | 일준 · 범찬 | API 서버, DB, 후보 추림, 매칭 · 규칙 로직, 시드 데이터, 엔진 연결 | `backend/` |
| **4. AI 시뮬레이션 엔진** | 건한 | 페르소나 생성, 에이전트 대화 루프, 판정자, 궁합 점수, 규칙 초안 | `engine/` |
