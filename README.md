## 왜 만드나요?

기숙사 2인실 룸메이트는 대부분 무작위나 단순 설문으로 정해집니다. 설문 점수로는 **"새벽 1시에 룸메이트가 통화하면?"** 같은 실제 장면의 반응을 알 수 없고, 갈등은 같이 살아 본 뒤에야 드러납니다.

```mermaid
flowchart TB
    subgraph NOW["지금 · 무작위 배정"]
        direction LR
        n1["입사 첫 주<br/>무작위 배정<br/>규칙 합의 없음"] --> n2["3주 차<br/>새벽 게임 소음<br/>수면 부족 누적"] --> n3["6주 차<br/>말하기 부담<br/>관계 악화"] --> n4["8주 차<br/>재배정 민원"]
    end
    subgraph NEW["룸메궁합"]
        direction LR
        m1["입사 전<br/>가상 동거로<br/>수면 리듬 충돌 확인"] --> m2["매칭<br/>수면 리듬이 맞는<br/>후보 선택"] --> m3["입주 첫날<br/>생활 규칙 6개 합의"] --> m4["학기 중<br/>불편은 AI 중재로<br/>조기 해소"]
    end
    NOW ~~~ NEW

    classDef bad fill:#fee2e2,stroke:#dc2626,color:#7f1d1d
    classDef good fill:#d1fae5,stroke:#059669,color:#064e3b
    class n1,n2,n3,n4 bad
    class m1,m2,m3,m4 good
```

**룸메이트 갈등의 주요 원인** (영국 대학생·학부모 4,000명 이상, 복수 응답, 2026)

| --- | --- |
| 소음 | `█████████████` 26% |
| 음식 무단 사용 | `████████████` 24% |

| 금전 대차 | `█████████▌` 19% |

## 무엇을 만드나요?

| | 기능 | 하는 일 |
| --- | --- | --- |
| 1 | **생활 페르소나** | 설문 + 상황 질문 12문항으로 수면·청결·소음·대화 방식을 분석해 나의 AI 분신을 만든다 |
| 2 | **가상 동거 시뮬레이션** | 내 AI와 후보의 AI가 가상 7일 동안 생활 장면 20개를 함께 겪으며 직접 대화하고 조율한다 |
| 3 | **생활 규칙 자동 작성** | 시뮬레이션에서 합의한 내용을 6개 영역의 생활 규칙 초안으로 정리한다 |
| 4 | **AI 중재** | 입주 후 불편을 요청형 문장으로 다듬어 전하고 규칙 재협상을 돕는다 |

### 사용자 흐름

```mermaid
flowchart LR
    A["A 생활 페르소나<br/>설문 · 상황 질문<br/>→ 나의 AI 분신"] --> B["B 가상 동거<br/>후보 3명과<br/>7일 · 장면 20개"]
    B --> C["C 매칭 · 생활 규칙<br/>리포트 보고 선택<br/>→ 규칙 초안 합의"]
    C --> D["D 함께 사는 동안<br/>불편 전하기 · 체크인<br/>AI 중재"]
```

### 가상 동거는 이렇게 돌아가요

```mermaid
flowchart LR
    PA["하늘 AI<br/>규칙적인 아침형"] --> MOD
    PB["다은 AI<br/>깔끔한 집순이"] --> MOD
    MOD["시뮬레이션 진행자<br/>가상 7일 · 장면 20개를<br/>하나씩 제시"] --> TALK["장면별 대화<br/>두 AI가 직접 조율"]
    TALK --> J{"판정"}
    J -->|"원만"| NEXT["다음 장면"]
    J -->|"조율"| RULE["규칙 후보 저장"]
    J -->|"충돌"| MED["합의안 제안"]
    RULE --> NEXT
    MED --> NEXT
    NEXT -.->|"20개까지 반복"| MOD
    NEXT --> OUT["궁합 점수 · 리포트<br/>생활 규칙 초안"]

    classDef ai fill:#ccfbf1,stroke:#0d9488,color:#134e4a
    classDef out fill:#e0e7ff,stroke:#4f46e5,color:#312e81
    class PA,PB ai
    class OUT out
```

**생활 장면 20개**

| 카테고리 | 장면 |
| --- | --- |
| 수면·소음 | 새벽 통화 · 심야 게임 · 이른 알람 · 드라이기 소음 |
| 청결·청소 | 설거지 미루기 · 욕실 머리카락 · 청소 당번 |
| 공용 물품 | 냉장고 반찬 · 휴지·세제 소진 · 물건 무단 사용 · 공과금 분담 |
| 방문객 | 친구 초대 · 연인 방문 · 늦은 귀가 |
| 환경 | 난방 온도 · 환기 · 조명 |
| 특수 기간 | 시험 기간 · 실습 주간 · 주말 늦잠 |

## 팀

```mermaid
flowchart LR
    PM["건한<br/>역할 1 · PM · 기획 · QA"]
    AI["건한<br/>역할 4 · AI 시뮬레이션 엔진"]
    FE["동현<br/>역할 2 · 프론트엔드"]
    BE["일준 · 범찬<br/>역할 3 · 백엔드 · 데이터"]

    PM -->|"설문 문항 · 장면 템플릿 20개"| AI
    PM -->|"화면 설계 · 우선순위"| FE
    AI -->|"엔진 함수 인터페이스"| BE
    BE -->|"REST · SSE API"| FE
    FE -->|"통합 빌드 · 버그 리포트"| PM
```

| 역할 | 담당 | 맡는 일 | 폴더 |
| --- | --- | --- | --- |
| **1. PM · 기획 · QA** | 건한 | 일정 관리, 설문 문항과 생활 장면 20개, 통합 테스트, 포스터 · 발표회 운영 | `docs/` `data/` |
| **2. 프론트엔드** | 동현 | 모바일 웹 화면(흐름 A~C), 시뮬레이션 실시간 화면 | `frontend/` |
| **3. 백엔드 · 데이터** | 일준 · 범찬 | API 서버, DB, 후보 추림, 매칭 · 규칙 로직, 시드 데이터, 엔진 연결 | `backend/` |
| **4. AI 시뮬레이션 엔진** | 건한 | 페르소나 생성, 에이전트 대화 루프, 판정자, 궁합 점수, 규칙 초안 | `engine/` |
